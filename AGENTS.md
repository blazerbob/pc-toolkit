# AGENTS.md

Правила для агента, работающего с этим репозиторием.

## Что это

PC Toolkit — GUI-приложение на Python + Tkinter для автоматизации Windows.
Никаких внешних зависимостей в рантайме: только стандартная библиотека.

## Команды

```powershell
# запуск приложения
python src\main.py

# тесты
python -m pytest

# линт и автофикс
python -m ruff check .
python -m ruff check --fix .
```

## Стиль

- Python 3.10+, `from __future__ import annotations`.
- Отступы 4 пробела, строка ≤ 100 символов (см. `pyproject.toml`).
- Русские docstring и комментарии — как в существующем коде.
- Комментарии только по делу, без очевидного.

## Архитектура (важно)

- `src/core/*` — **чистая логика**, без импортов tkinter. Каждый модуль должен
  тестироваться на временных каталогах (`tmp_path`) без касания реальной системы.
- `src/ui/*` — только представление; вся тяжёлая работа идёт через `core` и
  запускается в фоне (`run_async`), чтобы UI не подвисал.
- Новую функцию сначала добавляем в `core` с тестом, потом подключаем в `ui`.

## Границы

- Не удалять содержимое `%APPDATA%\PCToolkit` без явной просьбы.
- Не трогать реальные пользовательские файлы в тестах — только `tmp_path`.
- Не добавлять сторонние зависимости без согласования.

## Definition of done

1. `python -m pytest` — зелёный.
2. `python -m ruff check .` — без ошибок.
3. README обновлён, если менялось поведение.
