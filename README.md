# PC Toolkit — автоматизатор ПК

Приложение для Windows: одно окно с набором полезных действий в один клик.
Написано на Python + Tkinter, **без внешних зависимостей** (только стандартная
библиотека).

## Модули

| Вкладка | Что делает |
|---------|-----------|
| 🧹 **Очистка** | Временные файлы, кэш Windows, `Temp`, Prefetch — с предпросмотром объёма. Отдельная кнопка очистки корзины. |
| 📁 **Загрузки** | Раскладывает файлы по категориям: изображения, видео, аудио, документы, архивы, установщики, код. |
| 💾 **Бэкап** | Копирует выбранные папки в папку назначения с меткой даты. |
| 🚀 **Профили** | Сохраняет наборы программ и запускает их одним кликом (Работа / Игры / Учёба…). |
| ⏻ **Питание** | Выключение, перезагрузка, сон, гибернация по таймеру; отмена запланированного. |
| 📊 **Система** | Место на дисках, использование памяти, аптайм. |

Настройки хранятся в `%APPDATA%\PCToolkit\config.json`.

## Запуск

Требуется Python 3.10+ (у тебя 3.12). Двойной клик по **`run.bat`** либо:

```powershell
python src\main.py
```

## Тесты и линт

```powershell
python -m pytest
python -m ruff check .
```

(dev-зависимости: `python -m pip install -e ".[dev]"`)

## Структура

```
src/
├─ main.py          # точка входа
├─ core/            # чистая логика (тестируется отдельно)
│  ├─ cleaner.py    # очистка
│  ├─ organizer.py  # раскладка загрузок
│  ├─ backup.py     # бэкап
│  ├─ launcher.py   # профили запуска
│  ├─ power.py      # таймер питания
│  ├─ sysinfo.py    # инфо о системе
│  └─ config.py     # настройки (JSON)
└─ ui/              # окно на Tkinter
tests/              # pytest
```

## Предупреждения

- **Очистка системного `Temp` и Prefetch требует прав администратора** — при
  запуске без них часть файлов просто пропускается (не удаляется).
- **Очистка корзины необратима.**
- Модуль питания отправляет реальные команды системе — проверяй таймер.
